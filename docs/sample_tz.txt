Заказчик: региональная торговая сеть.
Нужна система учёта заявок на закупку для 300 сотрудников.
Требования: интеграция с 1С и SAP через API, ролевая модель и аудит действий,
хранение персональных данных по 152-ФЗ, отчёты и дашборды по статусам заявок.
Размещение: on-premise, внутри закрытого контура, без передачи данных наружу.
Сроки: запуск пилота за 5 месяцев. Поддержка: рабочие дни, 3 линия.
