# Архитектура Presale Lite

## Решение
Модульный монолит: UI (Streamlit) → REST API (FastAPI) → слой сценариев `PresaleService`
→ {`estimator` + `llm`, `pricing`, `documents`, `storage` (SQLite)}.

```
Streamlit UI ──HTTP──▶ FastAPI ──▶ PresaleService ──▶ Estimator ──▶ LLM (mock | OpenAI-compatible)
                                         │                 └──▶ Pricing (чистые функции)
                                         ├──▶ Documents (txt/md/docx/pdf)
                                         └──▶ Storage (SQLite)
```

## Ключевые решения
| Решение | Обоснование |
|---|---|
| Монолит вместо микросервисов | Один разработчик, один домен; проще развёртывание, отладка и сопровождение |
| SQLite вместо PostgreSQL + MinIO | Нет отдельных серверов; текст документов хранится в БД; достаточно для 30–50 пресейлов/мес |
| Провайдер LLM за интерфейсом | Замена модели без правок логики; `mock` даёт воспроизводимое демо и тесты без сети |
| Бюджет считается кодом, а не моделью | Модель оценивает только часы по ролям; деньги считаются детерминированно и проверяемо |
| Валидация ответа модели | Неизвестные роли, отрицательные часы, мусорный JSON отбрасываются до расчёта |
| Простая токен-авторизация | Достаточно для закрытого контура; сравнение токена в постоянном времени |

## Отличия от командной реализации
| | Команда (3 репозитория) | Presale Lite |
|---|---|---|
| Архитектура | 3 микросервиса + nginx | модульный монолит |
| Frontend | Next.js / TypeScript | Streamlit |
| БД и файлы | 2×PostgreSQL + MinIO | SQLite |
| Аутентификация | отдельный сервис, JWT RS256, роли, сессии | токен доступа |
| LLM | GigaChat / OpenAI | mock / OpenAI-совместимый API |
| Расчёт бюджета | в presale_service | отдельный модуль pricing, покрыт тестами |

## Ограничения (честно)
Нет ролей и многопользовательности, нет шифрования файлов, оценка зависит от качества модели,
в режиме mock результат правиловый и служит для демонстрации.
