# Отчёт по проекту «Presale Lite — AI-ассистент для пресейла IT-проектов»

*Черновик, структура соответствует критериям оценивания. Заполните [в скобках] своими данными.*

## 1. Цель и проблема (Функциональность)
Первичная оценка IT-проектов в пресейле делается вручную: долго и с разбросом точности. Цель — сократить
время подготовки предварительной оценки: ассистент принимает документы заказчика, задаёт уточняющие
вопросы, формирует ФТ/НФТ, декомпозицию, архитектуру, команду, бюджет и риски.
Тема совпадает с командным проектом; техническое решение разработано самостоятельно и отличается от командного
(см. docs/ARCHITECTURE.md).

## 2. Пользовательский сценарий
1. Создать пресейл (название, заказчик, описание, нужные результаты).
2. Загрузить ТЗ (txt/md/docx/pdf), при желании указать ставки специалистов.
3. Сформировать и заполнить вопросы преданализа.
4. Получить оценку: требования, задачи по ролям, архитектура, бюджет, расходы по месяцам, риски.
5. Скачать отчёт .md и задавать вопросы в чате.

## 3. Архитектура и стек (Код и архитектура)
См. docs/ARCHITECTURE.md. Стек: Python 3.12, FastAPI, SQLite, Streamlit, Docker Compose.
Принципы: слои без циклических зависимостей; бизнес-логика не зависит от веб-фреймворка;
провайдер LLM заменяем; деньги считаются кодом, а не моделью; ответ модели валидируется.

## 4. Реализация ключевых функций
- Загрузка и проверка документов (формат, размер, пустой файл, битый файл).
- Генерация вопросов с запасным списком при сбое LLM.
- Оценка: промпт → JSON → нормализация → расчёт бюджета (разработка, гарантия 8%, поддержка, помесячно).
- Хранение истории пресейлов и чата в SQLite.
- Авторизация токеном, обработка ошибок (401/404/422/502/409).
